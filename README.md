# قياس — موقع القياسات والفيديوهات

موقع لإدخال قياسات الطلاب مع معاينة ثلاثية الأبعاد حيّة، قسم فيديوهات،
ولوحة تحكم فيها رفع الفيديو وفتح/إغلاق الموقع واستخراج البيانات بملف PDF.

يعمل بوضعين:

| الوضع | متى | البيانات |
|---|---|---|
| **مشترك (سحابي)** | عند ملء ملف `.env` بمفاتيح Supabase | قاعدة بيانات واحدة يراها كل المشرفين، والتحديث يصل لحظيًا |
| **محلي** | بدون `.env` | كل متصفح يحتفظ ببياناته وحده — للتجربة السريعة |

---

## التشغيل

يحتاج **Node.js 20 أو أحدث** ([تحميل](https://nodejs.org)).

```bash
git clone https://github.com/mbaqer455-stack/-.git qias-studio
cd qias-studio

npm install      # مرة واحدة — تحميل المكتبات
npm run dev      # يفتح المتصفح تلقائيًا على http://localhost:5173
```

أوامر أخرى:

```bash
npm run build     # نسخة الإنتاج في مجلد dist
npm run preview   # معاينة نسخة الإنتاج
npm run typecheck # فحص الأنواع فقط
```

بدون إعداد إضافي يشتغل الموقع فورًا بالوضع المحلي، ورمز لوحة التحكم فيه `1234`.

## تشغيل الوضع المشترك (أنت + شريكك)

خمس خطوات، مرة واحدة فقط:

### ١. أنشئ مشروع Supabase
ادخل [supabase.com](https://supabase.com) ← سجّل دخول بحساب GitHub ← **New project**.
اختر اسمًا وكلمة مرور لقاعدة البيانات، والمنطقة الأقرب (Frankfurt مناسبة للعراق).
انتظر دقيقتين حتى يجهز المشروع.

### ٢. أنشئ الجداول
من القائمة الجانبية: **SQL Editor** ← **New query**.
افتح ملف [`supabase/schema.sql`](supabase/schema.sql) من هذا المشروع، انسخه كاملًا،
الصقه، واضغط **Run**. يُنشئ الجداول والصلاحيات ومخزن الملفات دفعة واحدة.

### ٣. أنشئ حسابي المشرفين
**Authentication** ← **Users** ← **Add user** ← **Create new user**:
- أدخل بريدك وكلمة مرور، وفعّل **Auto Confirm User**
- كرّر العملية لحساب شريكك

هذان الحسابان فقط يستطيعان الدخول للوحة التحكم — لا يوجد تسجيل ذاتي.

### ٤. انسخ المفاتيح إلى ملف `.env`
**Project Settings** ← **API**، ثم أنشئ ملف `.env` في جذر المشروع:

```env
VITE_SUPABASE_URL=https://xxxxxxxxxxxx.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGciOi...
```

> ملف `.env` مستثنى من Git — لا يُرفع للمستودع.
> أرسل المفاتيح لشريكك بشكل خاص، أو خذ نسخة من [`.env.example`](.env.example).

### ٥. أعد التشغيل

```bash
npm run dev
```

ستظهر شارة **«مشترك»** في لوحة التحكم. جرّب: افتح الموقع بجهازين وأدخل قياسًا —
يظهر عند الاثنين فورًا بدون تحديث الصفحة.

## من يستطيع ماذا

الصلاحيات محمية داخل قاعدة البيانات نفسها (Row Level Security)، مو بإخفاء أزرار
في الواجهة — يعني حتى لو حاول أحد يتجاوز الموقع، القاعدة ترفضه.

| | الطالب (بدون حساب) | المشرف (أنت وشريكك) |
|---|---|---|
| إدخال قياس | ✅ | ✅ |
| قراءة قياسات الطلاب | ❌ | ✅ |
| حذف قياس | ❌ | ✅ |
| مشاهدة الفيديوهات | ✅ | ✅ |
| رفع/حذف فيديو | ❌ | ✅ |
| فتح/إغلاق الموقع | ❌ | ✅ |

> مفتاح `anon` مُصمَّم ليكون علنيًا في المتصفح — الحماية من سياسات RLS،
> فلا تقلق من ظهوره في الكود المبني.

## الأقسام

### إدخال القياسات — `/measure`
ستة حقول، كل واحد مربوط بجزء من المجسّم:

| الحقل | يؤثر على |
|---|---|
| الطول | ارتفاع العمود والمجسّم كله |
| الوزن | عمق الجسم (السماكة) |
| العرض | اتساع الكتفين |
| عرض الصدر | انتفاخ منطقة الصدر + حجم شريط القياس |
| طول الصدر | طول الجذع |
| طول الكم | طول الذراع الإرشادية |
| الجنس | انحناءات الخصر والكتف |

بالإضافة إلى: الاسم، الرقم الجامعي، المرحلة/الشعبة، الهاتف، وملاحظات.
التحقق يعمل عند مغادرة الحقل مع رسالة خطأ تحت الحقل نفسه.

### قسم الفيديوهات — `/videos`
يعرض ما يُرفع من لوحة التحكم: صورة مصغّرة تُلتقط تلقائيًا من الفيديو، المدّة،
التاريخ، بحث، ومشغّل يفتح بنافذة.

### لوحة التحكم — `/admin`

| التبويب | المحتوى |
|---|---|
| نظرة عامة | أرقام سريعة + إجراءات مختصرة + آخر القياسات |
| بيانات الطلاب | جدول كامل + بحث + **استخراج PDF** + تصدير CSV + حذف |
| الفيديوهات | **رفع فيديو** (سحب وإفلات أو رابط) + قائمة المنشور + حذف |
| الإعدادات | **زر فتح/إغلاق الموقع** + نص رسالة الإغلاق + الحسابات |

**عن استخراج PDF:** يفتح نافذة الطباعة في المتصفح ومنها «حفظ كـ PDF».
هذه أدق طريقة للعربية لأنها تستخدم خطوط النظام وتشكيل RTL الصحيح، بدل تضمين
خط عربي داخل مكتبة PDF. تصميم الصفحة المطبوعة في قسم `@media print` داخل
[`src/index.css`](src/index.css).

**عند إغلاق الموقع:** يرى الزوار شاشة الإغلاق برسالتك على كل الأجهزة فورًا،
بينما تبقى لوحة التحكم متاحة لكم على `/admin`.

## حدود الخطة المجانية في Supabase

| المورد | الحد |
|---|---|
| مساحة قاعدة البيانات | 500 ميغابايت (تكفي عشرات الآلاف من القياسات) |
| مساحة الملفات | 1 غيغابايت — انتبه، الفيديوهات تأكلها بسرعة |
| نقل البيانات | 5 غيغابايت شهريًا |

نصيحة للفيديوهات الطويلة: ارفعها على يوتيوب أو Google Drive واستخدم خيار
**«رابط»** في لوحة التحكم بدل رفع الملف — يوفّر المساحة والنقل.

## ملاحظات الأداء

- مشهد الـ 3D يُحمَّل عند الطلب (`lazy`) — أول تحميل للصفحة خفيف.
- الرندر يتوقف كليًا عندما يخرج المشهد من الشاشة (IntersectionObserver).
- `dpr` محدود بـ 1.6 + `AdaptiveDpr` لخفض الدقة أثناء الحركة.
- بدون ظلال حقيقية: `ContactShadows` فقط، والإضاءة البيئية تُحسب مرة واحدة.
- الهندسة تُعاد بناؤها فقط عند تغيّر فعلي للقياس، والباقي تحريك سلس بالـ scale.
- كل الحركات على `transform` و`opacity` فقط، مع احترام `prefers-reduced-motion`.
- الصفحات مقسّمة لحزم منفصلة (code splitting).
