# قياس — قالب موقع القياسات والفيديوهات

قالب واجهة كامل (Front-end) جاهز للربط بأي خادم: إدخال قياسات الطلاب مع معاينة
ثلاثية الأبعاد حيّة، قسم فيديوهات، ولوحة تحكم فيها رفع الفيديو وفتح/إغلاق الموقع
واستخراج بيانات الطلاب بملف PDF.

---

## التشغيل

```bash
npm install      # مرة واحدة
npm run dev      # التطوير على http://localhost:5173
npm run build    # نسخة الإنتاج في مجلد dist
npm run preview  # معاينة نسخة الإنتاج
```

رمز الدخول للوحة التحكم في القالب: **1234** (يمكن تغييره من تبويب الإعدادات).

## الأقسام

### 1) إدخال القياسات — `/measure`
ستة حقول بالضبط كما طُلبت، كل واحد مربوط بجزء من المجسّم:

| الحقل | يؤثر على |
|---|---|
| الطول | ارتفاع العمود والمجسّم كله |
| الوزن | عمق الجسم (السماكة) |
| العرض | اتساع الكتفين |
| عرض الصدر | انتفاخ منطقة الصدر + حجم شريط القياس |
| طول الصدر | طول الجذع |
| طول الكم | طول الذراع الإرشادية |
| الجنس | انحناءات الخصر والكتف |

بالإضافة إلى: الاسم، الرقم الجامعي، المرحلة/الشعبة، الهاتف، وملاحظات.
التحقق يعمل عند مغادرة الحقل (on blur) مع رسالة خطأ تحت الحقل نفسه.

### 2) قسم الفيديوهات — `/videos`
يعرض ما يُرفع من لوحة التحكم: صورة مصغّرة تُلتقط تلقائيًا من الفيديو، المدّة،
التاريخ، بحث، ومشغّل يفتح بنافذة.

### 3) لوحة التحكم — `/admin`

| التبويب | المحتوى |
|---|---|
| نظرة عامة | أرقام سريعة + إجراءات مختصرة + آخر القياسات |
| بيانات الطلاب | جدول كامل + بحث + **استخراج PDF** + تصدير CSV + حذف |
| الفيديوهات | **رفع فيديو** (سحب وإفلات أو رابط) + قائمة المنشور + حذف |
| الإعدادات | **زر فتح/إغلاق الموقع** + نص رسالة الإغلاق + رمز الدخول |

**عن استخراج PDF:** يفتح نافذة الطباعة في المتصفح ومنها «حفظ كـ PDF».
هذه أدق طريقة للعربية لأنها تستخدم خطوط النظام وتشكيل RTL الصحيح، بدل تضمين
خط عربي داخل مكتبة PDF. تصميم الصفحة المطبوعة موجود في قسم `@media print`
داخل `src/index.css`.

**عند إغلاق الموقع:** يرى الزوار شاشة الإغلاق برسالتك، بينما تبقى لوحة التحكم
متاحة لك على `/admin`.

## الربط بالخادم

كل عمليات البيانات مجمّعة في كائن `api` داخل [`src/lib.ts`](src/lib.ts).
استبدل جسم كل دالة بنداء `fetch` — لا شيء في الواجهة يحتاج تعديلًا:

```ts
export const api = {
  async addSubmission(data) {
    const res = await fetch('/api/submissions', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(data),
    });
    return res.json();
  },
  // ... بقية الدوال
};
```

حاليًا في القالب:
- القياسات والإعدادات → `localStorage`
- ملفات الفيديو والصور المصغّرة → `IndexedDB` (تعمل فعليًا وتبقى بعد إعادة التحميل)

> **تنبيه أمني:** رمز لوحة التحكم يُفحص في المتصفح — للعرض فقط.
> عند الربط الحقيقي استبدله بمصادقة في الخادم (جلسة أو JWT) وتحقّق من الصلاحية
> في كل نداء، ولا تعتمد على إخفاء الواجهة وحده.

## ملاحظات الأداء

المشروع مضبوط ليكون سلسًا بدون تقطيع:

- مشهد الـ 3D يُحمَّل عند الطلب (`lazy`) — أول تحميل للصفحة خفيف.
- الرندر يتوقف كليًا عندما يخرج المشهد من الشاشة (IntersectionObserver).
- `dpr` محدود بـ 1.6 + `AdaptiveDpr` لخفض الدقة أثناء الحركة.
- بدون ظلال حقيقية: `ContactShadows` فقط، والإضاءة البيئية تُحسب مرة واحدة.
- الهندسة تُعاد بناؤها فقط عند تغيّر فعلي للقياس، والباقي تحريك سلس بالـ scale.
- كل الحركات على `transform` و`opacity` فقط، مع احترام `prefers-reduced-motion`.
- الصفحات مقسّمة لحزم منفصلة (code splitting).
